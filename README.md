# 往診ドクターの一日

### [▶ ゲームをはじめる](https://nqf18003.github.io/oushin-game-app/)

訪問診療の一日を再現したブラウザゲームです（フィクション。訪問診療の手順を学ぶための学習用）。`index.html` 1ファイルで動きます（ブラウザで開くだけ）。

- 9:00 に診療所を出発し、17:00 までに町を車で回って患者さんを診察します。
- 道の数字は通過にかかる分数。最短ルートで着くとボーナス。
- 定期訪問・初診（同意書・在宅療養計画書・訪問看護指示書など）・施設（同一建物の複数人）・急変の往診。
- 診察後に主な診療報酬（在医総管／施医総管、訪問診療料、HOT・在宅自己注射の指導管理料、往診料など）を選びます。

※ 診療報酬はゲーム用に簡略化しています。実際の算定は最新の告示・通知で確認してください。
